# ComBat 批次效應校正工具

## 📋 概述

本工具採用 ComBat 演算法針對代謝組學數據執行批次效應校正。ComBat 使用經驗貝氏（Empirical Bayes）方法消除不同批次（實驗批次、儀器批次）間的系統性差異，同時保留生物學變異。適用於多批次 LC-MS 或 GC-MS 實驗的整合分析。

## 🎯 為什麼需要 ComBat 校正？

### 批次效應的來源

在大規模代謝組學研究中，樣本常需分多個批次進行分析，導致批次間系統性差異：
- **不同實驗日期：** 儀器狀態、環境條件的時間變化
- **不同儀器：** 多台質譜儀的性能差異
- **不同操作人員：** 樣本製備和操作的個體差異
- **試劑批次：** 不同批次的試劑和耗材

### ComBat vs QC-LOWESS

- **QC-LOWESS：** 處理單一批次內的時間相關漂移（同一批次內的訊號衰減）
- **ComBat：** 處理多個批次之間的系統性偏移（不同批次間的整體差異）

兩者互補，通常流程為：ISTD 校正 → QC-LOWESS 校正 → ComBat 校正

### ComBat 的優勢

- **經驗貝氏框架：** 透過跨特徵資訊共享，提升小樣本批次的校正穩健性
- **保留生物變異：** 調整批次效應的同時，保留樣本組別的生物學差異
- **統計基礎扎實：** 廣泛應用於基因體學和代謝組學，經過大量驗證

## 🔧 核心功能

### 1. 自動化數據讀取

**工作表優先順序：**
```
QC LOWESS result > ISTD_Correction > RawIntensity
```

自動選擇最經過最多校正步驟的數據，並從 `SampleInfo` 工作表中提取批次資訊。

### 2. ComBat 批次效應校正

**演算法原理：**

ComBat 假設每個代謝物在不同批次中的強度差異可以分解為：
```
Y_batch = α + γ_batch + δ_batch × ε
```
- **α:** 整體平均水平
- **γ_batch:** 批次的位置偏移（加法效應）
- **δ_batch:** 批次的尺度偏移（乘法效應）
- **ε:** 誤差項

ComBat 透過經驗貝氏方法估算每個批次的 γ 和 δ 參數，並將所有批次標準化到同一參考水平。

**關鍵特色：**
- 使用所有代謝物的資訊來穩定參數估計（shrinkage）
- 對小批次樣本數具有穩健性
- 可選參數化或非參數化估計

### 3. 多維度評估指標

工具提供五種統計指標評估校正效果：

#### A. QC CV% (技術重現性)

最直接的數據穩定性指標。計算 QC 樣本的變異係數：

```
CV% = (標準差 / 平均值) × 100%
```

**評估標準：**
- QC CV% < 20%: 可接受
- QC CV% < 15%: 良好
- QC CV% < 10%: 優秀

**結果解讀：**
- 校正後 QC CV% 降低 → 技術重現性提升（理想）
- 校正後 QC CV% 上升 → 可能過度校正或引入新的變異（警示）

#### B. Cohen's d (效應量)

Cohen's d 衡量批次間的標準化平均差異，評估批次效應的「大小」：

```
Cohen's d = (μ₁ - μ₂) / σ_pooled
```

其中 σ_pooled 是合併標準差。對於多批次情況，工具計算所有批次對的平均 Cohen's d。

**效應量解釋：**
- |d| < 0.2: 小效應（批次差異不明顯）
- |d| = 0.2-0.5: 中等效應
- |d| = 0.5-0.8: 大效應
- |d| > 0.8: 極大效應（批次效應嚴重）

**結果解讀：**

假設校正前 Cohen's d = 0.8（大效應），校正後降至 0.2（小效應），表示批次效應被有效消除。

**為什麼重要？** 相較於 p 值（受樣本數影響），Cohen's d 提供標準化的效應大小，不受樣本數干擾。即使 p 值顯著，若 d 值很小，實際效應可能無意義。

#### C. PCA-ANOVA (主成分分析變異數分析)

評估批次效應對主成分的貢獻比例。執行流程：
1. 對數據進行 PCA 降維
2. 對 PC1 和 PC2 進行單因子 ANOVA，批次作為自變數
3. 計算 η² (eta squared) 效應量

**η² 計算公式：**
```
η² = SS_between / SS_total
```
表示批次效應解釋的變異比例。

**結果解讀：**
- **校正前：** η² 高且 p < 0.05 → 批次效應顯著影響主成分，樣本在 PCA 圖上按批次分群
- **校正後：** η² 降低且 p > 0.05 → 批次效應被消除，樣本不再按批次聚集

**實例：**
- 校正前 PC1: p < 0.001, η² = 0.45 → 批次解釋 45% 的 PC1 變異
- 校正後 PC1: p = 0.12, η² = 0.08 → 批次僅解釋 8% 的變異（不顯著）

#### D. Silhouette Coefficient (輪廓係數)

衡量樣本是否「按批次分群」的程度。Silhouette 係數範圍 [-1, 1]：

```
s(i) = [b(i) - a(i)] / max(a(i), b(i))
```
- **a(i):** 樣本 i 與同批次其他樣本的平均距離（內聚度）
- **b(i):** 樣本 i 與最近鄰批次樣本的平均距離（分離度）

**數值意義：**
- s → +1: 樣本緊密聚集在自己的批次內（批次效應嚴重）
- s → 0: 樣本在批次邊界上（批次效應不明顯）
- s → -1: 樣本更接近其他批次（可能分類錯誤或批次無效應）

**ComBat 的目標：** 降低 Silhouette 係數，讓樣本不再按批次聚集。

**結果解讀：**
- 校正前 Silhouette = 0.35 → 批次分離程度中等
- 校正後 Silhouette = 0.05 → 批次分離幾乎消失（理想）

#### E. Permutation Test (置換檢定)

評估 Silhouette 改善的統計顯著性。原理：

1. **觀測改善值：** 計算實際的 Silhouette 改善 (original - corrected)
2. **隨機置換：** 隨機打亂批次標籤 1000 次，每次重新計算改善值
3. **建立零分布：** 1000 個隨機改善值形成「無效應」的零分布
4. **計算 p 值：** 觀測改善值在零分布中的位置

**p 值計算：**
```
p-value = (隨機改善 ≥ 觀測改善的次數 + 1) / (置換次數 + 1)
```

**結果解讀：**
- **p < 0.05：** 改善顯著，ComBat 校正確實消除了批次效應
- **p > 0.05：** 改善不顯著，可能原本批次效應就很小，或校正無效

**為什麼需要 Permutation Test？**

Silhouette 改善值本身只是描述性統計，無法判斷是否「顯著」。透過置換檢定，我們能確認改善不是偶然產生的，而是 ComBat 真正發揮了作用。

#### F. FDR 校正 (False Discovery Rate)

對每個代謝物的 Permutation Test p 值進行 FDR 多重檢定校正。使用 Benjamini-Hochberg 方法控制假陽性率。

**目的：** 在大量檢定（數百個代謝物）中，避免因多重比較而產生的假陽性結果。

**結果解讀：**
- FDR < 0.05: 該代謝物的批次效應校正顯著有效
- 顯著代謝物比例: 例如 200/500 (40%) 表示有 40% 的代謝物顯著改善

### 4. 視覺化輸出

**PCA 對比圖（兩種分組模式）：**
- **按 Batch 分組：** 評估批次效應是否消除
- **按 Sample Type 分組：** 確認生物學變異是否保留

理想結果：校正後批次顏色混合，但樣本類型仍可區分。

**Permutation Test 分布圖：**
顯示零分布直方圖、觀測改善值位置和 p 值，視覺化統計顯著性。

## 💡 常見問題

**Q: 什麼時候需要使用 ComBat？**

當您的數據來自多個批次且符合以下情況：
1. PCA 圖顯示樣本按批次明顯分群
2. QC 樣本在不同批次間 CV% 差異大
3. 批次間平均強度存在系統性差異

**Q: ComBat 會不會消除生物學差異？**

ComBat 設計為「保留生物學變異」。它只調整批次間的系統性偏移，不改變批次內樣本間的相對關係。查看「按 Sample Type 分組」的 PCA 圖，確認生物學組別仍可區分。

**Q: 校正後 QC CV% 反而上升怎麼辦？**

可能原因：
1. 原始數據批次效應不明顯，ComBat 引入不必要的調整
2. 批次內變異大於批次間變異，ComBat 無法改善
3. 批次樣本數不平衡（某些批次樣本數過少）

建議：檢查校正前的 Cohen's d 和 PCA-ANOVA。如果原本效應就很小（d < 0.3, η² < 0.1），可能不需要 ComBat 校正。

**Q: 如何判斷 ComBat 校正是否成功？**

綜合評估五個指標：
- QC CV% 下降 ✓
- Cohen's d 顯著降低（> 50%）✓
- PCA-ANOVA η² 下降且 p 值上升 ✓
- Silhouette 改善且 Permutation p < 0.05 ✓
- FDR 顯著特徵比例 > 30% ✓

至少滿足 3-4 個條件即可認為校正成功。

**Q: 為什麼 Permutation Test 很重要？**

因為 Silhouette 改善值本身不告訴我們「改善是否顯著」。透過置換檢定，我們能確認改善不是隨機產生的，而是 ComBat 真正消除了批次效應。這提供了統計上的可信度。

## ⚙️ 技術細節

### 依賴套件
```
pandas, numpy, pycombat, scipy, scikit-learn, matplotlib, seaborn, openpyxl
```

### 核心演算法
- **ComBat:** pycombat 套件（經驗貝氏批次效應校正）
- **統計檢定:** 
  - Cohen's d (效應量)
  - 單因子 ANOVA (PCA-ANOVA)
  - Permutation test (1000 次置換)

- Permutation 次數: 1000
- FDR 閾值: 0.05
- Silhouette 距離度量: Euclidean

## 📝 注意事項

1. **批次數量：** 建議至少 2 個批次，最好 3 個以上
2. **批次樣本數：** 每批次至少 5 個樣本，避免樣本數過度不平衡
3. **數據前處理：** 建議先完成 ISTD 和 QC-LOWESS 校正
4. **QC 樣本：** 有 QC 樣本時，工具會計算 QC CV% 作為技術重現性指標
5. **生物學驗證：** 校正後務必檢查生物學組別的分離性是否保留

ComBat 校正完成後，建議進行：
1. **數據標準化：** Log 轉換、Pareto scaling 等
